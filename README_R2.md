# Внешние данные (роль R2)

Два коллектора, сборщик, валидатор, генератор карточек и слияние с набором из
PR #1. Все скрипты читают и пишут файлы относительно той папки, откуда их
запускают, так что гонять их надо из корня проекта, где лежат файлы Kaggle.

Порядок:

```
python src/collect/collect_chembl.py
python src/collect/collect_pubchem.py
python src/data/build_dataset_r2.py
python src/data/validate_dataset_r2.py
python src/data/make_cards.py
python src/data/merge_external.py
```

Коллекторы умеют докачку: упали или прервал — запускай снова, продолжит с
места обрыва. Служебные файлы `_done_*.txt` и `_ids_*.txt` в гит не кладём.
Последний шаг зависимостей не имеет, только стандартная библиотека, и работает
без собранного `.venv`.

## Какой файл брать для обучения

**`data/processed/vacv_external_merged.csv`, 851 молекула.** Это набор R2,
объединённый с чистой частью набора из PR #1. По одной строке на молекулу, и
`SI` равен `CC50 / IC50` из одной конкретной публикации, поэтому проверки из
`tests/test_dataset.py` на нём проходят. Что откуда взято и что отброшено — в
`reports/r2_merge_report.md`.

Остальные файлы промежуточные:

| Файл | Что внутри | Для обучения |
| --- | --- | --- |
| `vacv_external_merged.csv` | 851 молекула, объединённый набор | **да** |
| `vacv_external_molecules.csv` | 830 молекул, только R2 | нет, перекрыт объединённым |
| `vacv_external_usable.csv` | 934 пары «молекула и статья» | нет, см. ниже |
| `vacv_external_pairs_r2.csv` | 1333 пары, включая отбракованные | нет |
| `vacv_external_reported_only.csv` | 32 молекулы с готовым SI | нет, см. ниже |

`vacv_external_usable.csv` и `vacv_external_pairs_r2.csv` содержат отдельные
пары «молекула и статья»: одна молекула встречается несколько раз, и при
разбиении на свёртки это даст утечку.

`vacv_external_reported_only.csv` вынесен из обучения намеренно. Там SI взят
готовым из статьи, без IC50 и CC50, и 30 записей из 32 пришли из одной
публикации с SI ровно 8.0 на всю серию соединений. Это одно общее значение, а
не тридцать измерений.

## Колонки объединённого набора

Первыми идут пять обязательных: `smiles`, `IC50`, `CC50`, `SI`, `doi`.
Концентрации в микромолях, SI безразмерный. Дальше служебные:

| Колонка | Что означает |
| --- | --- |
| `origin` | `r2` или `pr1`, из какого набора пришла строка |
| `quality` | `exact` или `lower_bound`, усечён ли CC50 |
| `si_reliable` | `False`, если CC50 усечён: настоящий SI выше указанного |
| `source` | ChEMBL, PubChem или оба |
| `n_studies`, `si_min`, `si_max` | по скольким публикациям известна молекула и разброс SI между ними |
| `n_forms` | сколько стереоформ склеено в одну запись |
| `skeleton` | первые 14 символов InChIKey, ключ дедупликации |

Разброс между публикациями стоит использовать как вес: у молекул с большим
`si_max / si_min` значение менее надёжно.

## Проверки

`compare_train.py` считает пересечения с train и test, `agree.py` сверяет наш
SI с SI организаторов на общих молекулах.

**Важно:** оба читают `train.csv`, а по `CLAUDE.md` текущий файл организаторов
называется `train_v2.csv`. В старом `train.csv` заглушка равна 10000, в новом
нулю, и 81 строка расходится на четыре порядка. Перед сверкой скачайте
`train_v2.csv` и подставьте его, иначе результат недействителен.

Контрольные суммы обработанных файлов в `CHECKSUMS.txt`. Что внутри данных и
откуда они — в `DATASET_CARD_R2.md` и `SOURCES_R2.md`. Карточки генерирует
`make_cards.py`, править их руками не нужно.
