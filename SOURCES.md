# Источники данных

Все данные получены автоматически, скриптами из `src/collect/`. Поиск шёл
по вирусу и мишени, а не по списку молекул из теста. Вручную значения не
добавлялись и не исправлялись.

Сырые ответы API сохраняются в `data/external/cache/`, поэтому повторная
сборка даёт тот же результат, даже если содержимое баз изменится.

## ChEMBL

| | |
|---|---|
| Адрес API | https://www.ebi.ac.uk/chembl/api/data |
| Веб-интерфейс | https://www.ebi.ac.uk/chembl/ |
| Скрипт | `src/collect/chembl_vacv.py` |
| Лицензия | CC BY-SA 3.0 |
| Условия | https://chembl.gitbook.io/chembl-interface-documentation/about |

Запросы:

1. `GET /assay?assay_organism__icontains=vaccinia` — ассеи, поставленные на
   вирусе осповакцины. Найден 621 ассей в 284 публикациях.
2. `GET /activity?document_chembl_id__in=...&standard_type__in=IC50,EC50,CC50,TC50,CD50,GI50,ID50`
   — все измерения нужных типов из этих публикаций, включая
   цитотоксичность на клетках хозяина.
3. `GET /document?document_chembl_id__in=...` — DOI и PubMed ID публикаций.

Почему именно так. Противовирусную активность измеряют на вирусе, а
цитотоксичность на клетках хозяина, поэтому ассеи с CC50 помечены другим
организмом и по запросу «vaccinia» не находятся. Но обе величины почти
всегда опубликованы в одной статье, поэтому мы идём от публикаций.

## PubChem BioAssay

| | |
|---|---|
| Адрес API | https://pubchem.ncbi.nlm.nih.gov/rest/pug |
| Поиск ассеев | https://eutils.ncbi.nlm.nih.gov/entrez/eutils |
| Скрипт | `src/collect/pubchem_vacv.py` |
| Лицензия | данные открыты, права на каждый набор задаёт депозитор |
| Условия | https://www.ncbi.nlm.nih.gov/home/about/policies/ |

Запросы:

1. `esearch.fcgi?db=pcassay&term=vaccinia+virus` и `term=orthopoxvirus` —
   идентификаторы ассеев.
2. `GET /assay/aid/<AID>/summary/JSON` — название, описание, PubMed ID.
   Ассей берётся в работу, только если вирус упомянут в названии или
   описании.
3. `GET /assay/aid/<AID>/concise/JSON` — таблица измерений.
4. `GET /compound/cid/<CIDs>/property/SMILES,MolecularWeight/JSON` —
   структуры и молекулярные массы.

Ограничение скорости PubChem — не более 5 запросов в секунду, скрипт
выдерживает паузу между запросами.

## Что не использовалось

**BindingDB** — содержит в основном данные по отдельным ферментам, а не по
подавлению вируса в клеточной культуре. Смешивать их с клеточными IC50
нельзя, получились бы несопоставимые величины.

**Родственные вирусы** (оспа коров, оспа обезьян) — в основной набор не
вошли, потому что селективность к ним отличается. При необходимости их
можно собрать тем же скриптом, заменив строку поиска.

**Статьи без машинного доступа** — ручное извлечение значений из PDF
не проводилось, это нарушило бы требование воспроизводимости.

## Проверка

`python -m src.data.validate_dataset` печатает адреса всех источников,
проверяет их доступность и заново запрашивает у API 20 случайных записей,
сравнивая их с тем, что лежит в собранном датасете. Отчёт сохраняется в
`reports/dataset_validation.md`.
