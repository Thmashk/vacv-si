# Карточка датасета

Файл: `data/processed/vacv_external_dataset.csv`

Набор данных об активности малых молекул против вируса осповакцины,
собранный автоматически из открытых баз для хакатона. Нужен как внешнее
дополнение к обучающей выборке организаторов, в которой всего 320 молекул.

## Как собирался

```bash
make data           # выгрузка из баз и сборка
make validate-data  # проверка
```

Три этапа, каждый в своём скрипте:

1. **Выгрузка.** `src/collect/chembl_vacv.py` и `src/collect/pubchem_vacv.py`
   забирают измерения из ChEMBL и PubChem. Поиск идёт по вирусу и мишени,
   а не по списку молекул из теста. Адреса всех запросов перечислены в
   [SOURCES.md](SOURCES.md). Ответы API кэшируются в `data/external/cache/`,
   поэтому повторная сборка воспроизводима.
2. **Сборка.** `src/data/build_dataset.py` стандартизует структуры, схлопывает
   повторы, спаривает активность с цитотоксичностью и считает SI.
3. **Проверка.** `src/data/validate_dataset.py` проверяет схему, формулу,
   DOI, структуры, доступность источников и заново сверяет 20 случайных
   записей с API. Отчёт: `reports/dataset_validation.md`.

## Ключевое решение: как спаривались IC50 и CC50

Противовирусную активность измеряют на вирусе, а цитотоксичность на клетках
хозяина. Поэтому ассеи с CC50 помечены другим организмом и по запросу
«vaccinia» не находятся. Но обе величины почти всегда публикуются в одной
статье, одной группой, в одних условиях.

Поэтому сбор идёт от публикаций: находим ассеи по вирусу, берём все
публикации, где они встречаются, и выгружаем оттуда все измерения нужных
типов. Затем к каждой активности подбирается цитотоксичность **из той же
публикации**. Такие пары помечены `pairing_quality = same_document` и
составляют подавляющее большинство. Если в публикации цитотоксичности нет,
берётся медиана по другим публикациям, и запись помечается
`other_document` как менее надёжная.

## Колонки

Первыми идут пять колонок, обязательных по условиям задачи.

| Колонка | Что означает |
|---|---|
| `smiles` | канонический SMILES крупнейшего фрагмента, без солей |
| `IC50` | концентрация полумаксимального подавления вируса, мкМ |
| `CC50` | концентрация полумаксимальной цитотоксичности, мкМ |
| `SI` | индекс селективности, `CC50 / IC50` |
| `doi` | DOI публикации, откуда взяты значения |

Служебные колонки:

| Колонка | Что означает |
|---|---|
| `inchikey` | ключ молекулы, по нему ищутся повторы |
| `source` | база: ChEMBL или PubChem |
| `ic50_type` | что именно измеряли: IC50, EC50 или ID50 |
| `organism` | организм ассея |
| `document_id`, `pubmed_id`, `assay_id` | идентификаторы в исходной базе |
| `pairing_quality` | `same_document` или `other_document` |
| `ic50_censored`, `cc50_censored` | значение было вида «>100», а не точным |
| `si_reliable` | `False`, если цензурированы обе величины |
| `n_ic50`, `n_cc50` | сколько измерений усреднено |
| `ic50_log_spread` | разброс между повторами, в порядках величины |

## Обработка значений

**Единицы.** Всё приведено к микромолям. Массовые единицы (мкг/мл)
пересчитаны через молекулярную массу, посчитанную RDKit. Если надёжно
пересчитать нельзя, запись отброшена: потерять строку лучше, чем внести
ошибку в три порядка.

**Повторы.** Если молекулу измеряли несколько раз в одной публикации,
берётся медиана логарифмов. Концентрации распределены логнормально,
поэтому усреднять нужно логарифмы, а не сами значения. Разброс между
повторами сохранён в `ic50_log_spread`.

**Структуры.** Удалены соли и сольваты, оставлен крупнейший органический
фрагмент, SMILES приведён к каноническому виду. Повторы ищутся по InChIKey,
а не по строке SMILES: одна молекула записывается десятком разных строк.

**Одна строка на молекулу.** При нескольких подходящих парах выбирается
самая надёжная: сначала с точными значениями, затем из одной публикации,
затем с наибольшим числом измерений.

## Важное ограничение: цензурированные значения

Заметная часть записей в базах имеет вид «>100» — это значит, что при
максимальной проверенной концентрации эффекта не наблюдали, и настоящее
значение неизвестно.

Если цензурированы **обе** величины, например IC50 > 100 и CC50 > 100, их
отношение механически даёт SI = 1, хотя настоящая селективность может быть
любой. Такие строки помечены `si_reliable = False`. **Обучаться на них как
на настоящих измерениях нельзя** — модель выучит артефакт обработки данных,
а не химию. Используйте фильтр `si_reliable` или понижайте вес таких строк.

## Пересечение с данными организаторов

Часть молекул внешнего набора встречается в train и test соревнования.
Это получилось само: поиск шёл по вирусу, а не по списку теста. Точные
числа печатает `make validate-data` и сохраняет в
`reports/dataset_validation.md`.

Пересечение с train полезно для сверки: оно показывает, одинаково ли мы с
организаторами понимаем определение SI. Пересечение с test требует
согласования с организаторами, прежде чем обучаться на этих строках.
Вопрос им задан.

## Что в набор не вошло

* данные по отдельным ферментам (BindingDB) — несопоставимы с клеточными
  измерениями;
* родственные вирусы (оспа коров, оспа обезьян) — другая селективность;
* значения из статей без машинного доступа — ручное извлечение нарушило бы
  воспроизводимость.
