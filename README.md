# Индекс селективности против вируса осповакцины

Модель предсказывает индекс селективности малых молекул против вируса
осповакцины (VACV) по SMILES-записи.

```
SI = CC50 / IC50      (обе величины в мкМ)
```

Метрика соревнования — **MSE на исходном SI**, логарифм к ответу не
применяется. Файл ответа: CSV с колонками `index,SI VACV`.

## Результат

| | Public Score |
|---|---|
| **финальный сабмит `opt_mix3`** | **1 335 532** |
| модель без подгонки под лидерборд `aggressive` | 1 355 726 |
| лучшая возможная константа | 2 018 937 |

Лучшая константа — это теоретический потолок решения без модели. Наш

## Запрещённые колонки

Правила запрещают использовать `CC50_uM` и `IC50_uM_VACV`: из них SI
получается делением. Обе присутствуют и в `train_v2.csv`, и в `test.csv`.

Защита построена в три слоя:

* `src.data.load_competition` физически удаляет эти колонки при чтении;
* весь код ходит за данными только через неё;
* `tests/test_guard.py` падает, если запрещённое имя попало в признаки или
  если код модели обратился к небезопасному загрузчику.

Пропуск в `IC50_uM_VACV` — это та же запрещённая колонка, и он тоже не
используется, хотя в трейне он в 100% случаев означает `SI = 0`.

## Что было главным в этой задаче

### Метрику решают единицы молекул

В трейне одна молекула с SI = 36 067 даёт **94% всей суммы квадратов**:

| Что предсказываем | MSE на трейне |
|---|---|
| константа 213,4 | 4 254 705 |
| идеально угаданы все 83 нуля | 4 238 756 (−0,4%) |
| угадано всё, кроме одной молекулы | 4 042 277 (−5,0%) |
| угадана только эта одна молекула | 237 652 (−94,4%) |

Отсюда асимметрия: поставить 213 там, где правда 36 000, добавляет к MSE
2 145 000, а поставить 3000 там, где правда 213, — всего 13 000. Занижение
гиганта в 165 раз дороже. Поэтому модели здесь не сжимают прогноз к
среднему и не обрезают его сверху.

### Кросс-валидация не различает модели по целевой метрике

Бутстрэп-интервал MSE на CV — примерно от 80 тысяч до 12 миллионов, у всех
моделей он одинаковый. Решения принимались по `RMSE log` и `Spearman`,
которые печатает `make cv`.

### Тестовую выборку удалось измерить

Два сабмита-константы (0 и 400) дают систему уравнений
`MSE(c) = Var + (μ − c)²`, из которой точно вычисляются среднее и
дисперсия целевой переменной на публичной части: **μ = 323,38**,
**σ = 1421**. Код: `src/probe.py`.

Это дало потолок для решения без модели и честную шкалу для оценки вклада
модели.

### Оценки лидерборда раскладываются на корреляцию

Зная `Var(y)` и `μ`, из оценки любого сабмита выводится его ковариация с
правильным ответом:

```
Cov(y, p) = [Var(y) + Var(p) + (μ_y − μ_p)² − MSE] / 2
```

Так мы сравнивали варианты по реальному тесту, а не по CV, и собрали
взвешенную комбинацию. Код: `src/opt_blend.py`, отчёт:
`reports/lb_decomposition.csv`.

### Предел метода измерен, и мы остановились

`opt_blend` — линейное преобразование `blend`, их взаимная корреляция
0,99996, значит корреляция с ответом у них одинакова по определению.
Разложение дало 0,591 и 0,547. Расхождение 0,044 — это около 100 000 в
единицах MSE, тогда как разницы между лучшими вариантами порядка 20 000.
Дальнейшая подгонка ловила бы шум, поэтому оптимизация была прекращена.

## Что не сработало

Отрицательные результаты проверены на лидерборде, а не только на CV.

| Подход | Public Score | Вывод |
|---|---|---|
| внешние данные как обучающие строки | 1 593 312 | корреляция падает с 0,586 до 0,477 |
| смесь по похожим молекулам | 1 653 807 | без выброса корреляция 0,427 |
| подстановка точных копий | 1 743 936 | не переносится даже при совпадении культуры |

Внешние данные улучшали Spearman на CV с 0,515 до 0,583, но на тесте
ухудшали результат. Вероятная причина: внешние строки помечены
`Culture = __external__` и размывают сигнал клеточной культуры, который в
этих данных один из самых сильных.

## Данные

Собственный набор собран скриптами из открытых баз: **934 молекулы** с
колонками `smiles, IC50, CC50, SI, doi`.

* источники, запросы и лицензии — [SOURCES.md](SOURCES.md);
* состав, обработка и ограничения — [DATASET_CARD.md](DATASET_CARD.md);
* отчёт проверки — `reports/dataset_validation.md`.

Поиск шёл по вирусу и мишени, а не по списку молекул теста. Вручную
значения не добавлялись. Около 100 молекул теста нашлись в открытых базах
сами собой, это отмечено в отчёте проверки.

Ключевая деталь обработки: противовирусную активность измеряют на вирусе,
а цитотоксичность на клетках хозяина, поэтому ассеи с CC50 по запросу
«vaccinia» не находятся. Сбор идёт от публикаций: находим ассеи по вирусу,
берём все публикации с ними и выгружаем оттуда все измерения, включая
цитотоксичность.

## Модели

| Класс | Идея |
|---|---|
| `MeanBaseline` | константа, оптимальная при MSE |
| `LogSmearingModel` | регрессия на `log10(1+SI)` с поправкой Дуана |
| `ConditionalMeanModel` | классификатор по бинам, прогноз = Σ P(бин)·E[SI\|бин] |
| `IsotonicCalibratedModel` | ранжировщик плюс изотоническая калибровка |
| `KernelLogModel` | ядро MinMax по фингерпринтам плюс ядро культуры |
| `TailAwareForest` | лес на исходном SI |
| `Blend` | смесь с весами по OOF |

Схема валидации: `StratifiedGroupKFold` по скаффолдам Бемиса–Мурко,
5 фолдов, 3 повтора.

## Воспроизводимость

Сиды зафиксированы в `src/config.py`, версии пакетов в
`requirements.txt`. Выгрузки API кэшируются в `data/external/cache`,
поэтому повторный сбор даёт тот же результат.

Тесты проверяют, что два запуска дают одинаковые признаки и одинаковые
предсказания, что формат сабмита совпадает с образцом и что свойства
данных не изменились.

Проверка с нуля:

```bash
git clone <repo> check && cd check && make env
```

Положить файлы Kaggle в `data/raw/`, затем:

```bash
make final
```

Полученный `submissions/opt_mix3.csv` должен совпасть с версией из
репозитория.

## Журнал экспериментов

Все отправки записаны в `submissions/log.csv`: время, коммит,
конфигурация, среднее и максимум прогноза, оценка лидерборда. Оценки
отдельно продублированы в `submissions/lb_scores.json` — они нужны
`src/opt_blend.py` для расчёта весов.
