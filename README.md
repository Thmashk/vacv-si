# VACV SI — предсказание индекса селективности по SMILES

Модель предсказывает индекс селективности малых молекул против вируса
осповакцины (VACV) по SMILES-записи. Метрика соревнования — **MSE на исходном
SI**, логарифм к ответу не применяется.

```
SI = CC50 / IC50      (обе величины в мкМ)
```

## Быстрый старт

```bash
make env
```

```bash
make test
```

```bash
make cv
```

```bash
make submit
```

`make all` делает всё по очереди и кладёт файл в `submissions/`.

## Главный факт про эти данные

MSE на исходном SI определяется несколькими экстремальными молекулами.
В трейне из 320 строк **одна** молекула (`8e-as-555-15-16`, SI = 36 067)
даёт 94% всей суммы квадратов:

| Что предсказываем | MSE на трейне | Изменение |
|---|---|---|
| константа 213,4 (среднее) | 4 254 705 | — |
| идеально угаданы все 83 нуля | 4 238 756 | −0,4% |
| угадано всё, кроме одной молекулы | 4 042 277 | −5,0% |
| угадана только эта одна молекула | 237 652 | **−94,4%** |

Отсюда два следствия, на которых построен весь код.

**Первое. Занижать хвост намного дороже, чем завышать середину.**
Вклад одной строки теста в MSE (тест из 597 строк):

| Ситуация | Добавка к MSE |
|---|---|
| поставили 3000, правда 213 | +13 000 |
| поставили 213, правда 36 000 | +2 145 000 |

Разница в 165 раз. Поэтому модели здесь не сжимают прогноз к среднему и не
обрезают его сверху: под MSE оптимален условный средний, а у него тяжёлый
правый хвост.

**Второе. Сравнивать модели по MSE на кросс-валидации нельзя.**
Бутстрэп-интервал MSE примерно от 80 тысяч до 12 миллионов, у всех моделей он
одинаковый. Поэтому `src/run_cv.py` печатает ещё `RMSE log` и `Spearman` —
там сигнал есть, и решения принимаются по ним.

## Запрещённые колонки

Правилами запрещено использовать `CC50_uM` и `IC50_uM_VACV`: из них SI
получается делением. Обе колонки присутствуют и в `train_v2.csv`, и в
`test.csv`.

Защита построена так:

* `src/data.load_competition` физически удаляет эти колонки при чтении файла;
* всё остальное в `src/` ходит за данными только через неё;
* `tests/test_guard.py` падает, если запрещённое имя всплыло в признаках
  или если код модели обратился к небезопасному загрузчику.

Отдельно: **пропуск в `IC50_uM_VACV` — это та же запрещённая колонка.**
В трейне пропуск IC50 означает SI = 0 ровно в 100% случаев, в тесте таких
строк 127. Использовать этот факт нельзя без письменного разрешения
организаторов, и код этого не делает.

## Устройство целевой переменной

| | train_v2.csv |
|---|---|
| строк | 320 |
| строк без IC50 | 81, у всех SI = 0 |
| строк без CC50 | 2, у них тоже SI = 0 |
| нулей всего | 83 (25,9%) |
| медиана SI | 1,84 |
| максимум SI | 36 066,7 |

Формула `SI = CC50 / IC50` проверена на 237 строках, где обе величины
измерены: совпадает везде. Тест фиксирует оба свойства, и если организаторы
обновят файл, он упадёт.

## Модели

| Класс | Идея |
|---|---|
| `MeanBaseline` | константа, равная среднему. Оптимальная константа при MSE |
| `LogSmearingModel` | регрессия на `log10(1 + SI)` с поправкой Дуана при обратном переходе |
| `ConditionalMeanModel` | классификатор по бинам SI, прогноз = Σ P(бин) · E[SI\|бин] |
| `IsotonicCalibratedModel` | лог-модель как ранжировщик плюс изотоническая калибровка в условное среднее |
| `TailAwareForest` | лес прямо на исходном SI, независимый взгляд |
| `Blend` | смесь с весами, подобранными на OOF |

`ConditionalMeanModel` — основная конструкция. Она оценивает условное
математическое ожидание напрямую, поэтому хвост попадает в прогноз через
вероятность верхнего бина: даже 10% уверенности в высокой селективности
поднимают ответ на порядок, и под MSE это выгодно.

Параметр `--tail-scale` умножает среднее верхнего бина. Это ручка риска:
`1.0` — честная условная средняя, больше — агрессивнее на хвосте.

## Результаты кросс-валидации

Схема: `StratifiedGroupKFold` по скаффолдам Бемиса–Мурко, 5 фолдов, 3 повтора.

| модель | MSE | RMSE log | Spearman |
|---|---|---|---|
| лог + smearing | 4 276 840 | **0,770** | **0,519** |
| лог + изотоника | 4 362 667 | 1,209 | 0,494 |
| смесь | 4 221 479 | 1,394 | 0,438 |
| условное среднее | 4 236 685 | 1,493 | 0,404 |
| лес на исходном SI | 4 727 292 | 1,401 | 0,364 |
| константа | 4 280 907 | 1,760 | −0,024 |

Столбец MSE здесь не различает модели: интервалы полностью перекрываются.
Ранжирует лучше всех лог-модель, и именно её выход калибруется в условное
среднее.

Свежие числа — в `reports/cv_results.md` после `make cv`.

## Что делает сборка сабмита сверх предсказания

* подставляет известные ответы для молекул, которые есть и в трейне, и в
  тесте: после стандартизации SMILES совпадают **30 строк теста**, из них 24
  с совпадением и по клеточной культуре;
* выдаёт одинаковый прогноз одинаковым молекулам внутри теста;
* проверяет формат по `sample_submit.csv`: колонки, порядок индексов,
  отсутствие `NaN` и отрицательных значений;
* дописывает строку в `submissions/log.csv` с временем, коммитом и настройками.

## Признаки

Счётный фингерпринт Morgan (1024 бита, радиус 2), 29 дескрипторов RDKit,
one-hot по клеточной культуре и флаги штамма. Культура разрешена правилами и
несёт много сигнала: средний SI в BSC-40 равен 1497, в Vero — 283, в HeLa — 4.
Все культуры из теста присутствуют в трейне.

## Чего здесь пока нет

Скрипты сбора внешних данных из ChEMBL и PubChem (`src/collect/`),
`DATASET_CARD.md` и `SOURCES.md`. По условиям это **обязательно** для допуска
к защите наравне с местом в таблице. Собранный датасет должен лежать в
`data/processed/` с колонками `smiles, IC50, CC50, SI, doi`.

## Воспроизводимость

Сиды зафиксированы в `src/config.py`, версии пакетов в `requirements.txt`.
`tests/test_guard.py` проверяет, что два запуска дают одинаковые признаки и
одинаковые предсказания. Перед сдачей прогоните `make all` на чистом клоне на
другой машине.
