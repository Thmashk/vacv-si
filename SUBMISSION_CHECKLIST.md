# Чек-лист сдачи

## Требования организаторов и чем они закрыты

| Требование | Чем закрыто | Готово |
|---|---|---|
| Модель предсказывает SI по SMILES | `src/models.py`, `src/run_cv.py` | да |
| Формат сабмита `index,SI VACV` | проверяется в `src/make_submission.py` и тестом | да |
| Скрипт загрузки из открытых баз | `src/collect/` | да |
| Датасет `smiles, IC50, CC50, SI, doi` | `data/processed/vacv_external_usable.csv` | да |
| Скрипт валидации с указанием источников | `src/data/validate_dataset.py`, `SOURCES.md` | да |
| Ссылка на GitHub | репозиторий, публичным после дедлайна | нет |
| Воспроизводимость пайплайна | `make final` даёт отправленный файл точно | да |

## Перед дедлайном

- [ ] **Отметить два финальных сабмита** в колонке Select на Kaggle.
      Если не отметить, засчитают лучший по публичной части, а он
      переобучен под 30% теста.
      Рекомендация: лучший по публике плюс `aggressive` — он получен
      только по кросс-валидации, без оглядки на лидерборд.
- [ ] **Проверка на чужой машине.** Клонировать с нуля, `make env`,
      положить файлы Kaggle в `data/raw/`, запустить `make final`,
      сверить результат с `submissions/opt_mix3.csv`.
- [ ] `git pull && make test` — все тесты зелёные.
- [ ] Все ветки влиты в `main`, открытых пул-реквестов нет.
- [ ] Тег релиза:

```bash
git tag -a v1.0-final -m "финальная версия" && git push origin v1.0-final
```

## После дедлайна

- [ ] Сделать репозиторий публичным:

```bash
gh repo edit Thmashk/vacv-si --visibility public --accept-visibility-change-consequences
```

- [ ] Отправить организаторам ссылку на репозиторий.
- [ ] Подготовить питч по плану в `reports/`.

## Для проверяющего: как убедиться, что запрещённые колонки не использованы

```bash
make test
```

Тест `test_forbidden_columns_never_reach_features` падает, если имя
`CC50_uM` или `IC50_uM_VACV` попало в матрицу признаков. Тест
`test_unsafe_loader_is_not_imported_by_model_code` падает, если код
моделей обратился к загрузчику, который эти колонки сохраняет.

Единственная функция, читающая файл целиком, —
`src.data.load_competition_unsafe`, и она используется только в
проверках свойств данных, не в обучении.
